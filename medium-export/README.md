# Medium export

Open either HTML file in a browser, select all, copy it, and paste it into the body of a blank Medium draft. Add the matching title separately in Medium's title field.

- `part-1.html`
- `part-2.html`

## Titles

- Part 1: `Building an On-Device Video Editor app with Swift/SwiftUI and SpeechAnalyzer — Part 1`
- Part 2: `Building an On-Device Video Editor app with Swift/SwiftUI and SpeechAnalyzer — Part 2`

The pages use semantic headings, lists, links, inline code, and `<pre><code>` blocks so rich-text copying preserves the article structure better than Medium's URL importer.
